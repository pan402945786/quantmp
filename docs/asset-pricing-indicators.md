# 资产定价与量化研究指标库

> 整理日期：2026-11-09。本文服务于资产研究与策略验证，不构成交易建议。指标是研究输入，不代表可以直接产生稳定收益。

## 1. 如何使用这份指标库

先区分四类问题：

| 用途 | 回答的问题 | 例子 |
| --- | --- | --- |
| 估值 | 价格相对于现金流、资产、供给或使用情况如何？ | DCF、P/E、MVRV |
| 风险与收益因子 | 哪些特征和风险暴露可能解释收益差异？ | 市场 Beta、价值、动量 |
| 市场状态与交易信号 | 资金、订单和价格近期发生了什么？ | 盘口深度、资金费率、OI 变化 |
| 执行与风险控制 | 能否按合理成本成交，亏损是否可承受？ | 买卖价差、滑点、波动率 |

一个指标可以同时服务多个用途。估值偏离不意味着价格马上回归；风险相关性不等于可交易利润；历史预测能力也不保证未来有效。

## 2. 现金流与股票相对估值

| 指标 | 常用口径 | 适用与限制 |
| --- | --- | --- |
| 股东自由现金流 FCFE | 企业支付经营成本、投资及债务相关现金流之后，可供股东分配的现金流 | 适合股权估值；应与股权成本匹配 |
| 企业自由现金流 FCFF | 企业经营产生、扣除必要再投资后，可供债权人和股东分配的现金流 | 适合企业整体估值；应与加权平均资本成本 WACC 匹配 |
| 现金流折现 DCF | 分期预测现金流，按匹配的折现率折现，并估算终值 | 对增长率、折现率和终值假设敏感 |
| 现金流增长率 | 可比较期间现金流的增长率 | 周期性、一次性项目和基数会影响解释 |
| 市盈率 P/E | 股权市值 / 净利润，或股价 / 每股收益 | 分清历史与预测利润；亏损时通常不适合直接比较 |
| 市净率 P/B | 股权市值 / 账面股东权益 | 结合盈利能力和行业比较；账面权益为负时不宜直接使用 |
| 市销率 P/S | 股权市值 / 营业收入 | 不反映成本结构，需结合利润率 |
| EV/EBITDA | 企业价值 / 息税折旧摊销前利润 | 比较企业整体时使用；不能忽略资本开支和营运资金 |
| 股息率 | 每股年度股息 / 当前股价 | 历史股息不保证未来持续 |
| 股权自由现金流收益率 | FCFE / 股权市值 | 应核查现金流质量与可持续性 |

DCF 的基本形式是 `价值 = 各期预期现金流的折现值之和 + 终值的折现值`。低估值倍数可能反映低增长、高风险或盈利质量问题，不能单独作为低估结论。

## 3. 风险与收益因子

| 指标或特征 | 常用口径 | 用途与限制 |
| --- | --- | --- |
| 市场 Beta | 在指定窗口内，资产收益对市场收益回归得到的斜率 | 衡量相对市场的线性敏感性；随窗口变化 |
| 市值 Size | 股价乘以股数，研究时常取对数 | 比较不同规模资产；要注意流动性差异 |
| 价值 Value | 如账面股东权益 / 股权市值 | 比较价值特征；需使用当时已公布的数据 |
| 盈利能力 Profitability | 如经营利润相对账面权益 | 比较盈利水平；具体因子定义需固定 |
| 投资强度 Investment | 如总资产增长率 | 衡量扩张；需要可追溯的财报发布时间 |
| 动量 Momentum | 某历史窗口内累计收益，或相对其他资产的收益排名 | 检验趋势延续；需要明确窗口和是否跳过最近一期 |
| 波动率 | 指定窗口内收益率的标准差 | 可用于风险缩放；不是稳定的收益方向信号 |
| 特质波动率 | 剔除选定因子后残差收益的波动率 | 结果依赖所选因子模型 |

**特征、因子收益和因子暴露不同。**例如，公司市值是特征；按市值构造组合得到的收益差是因子收益；某资产收益对该因子的敏感性是因子暴露。Fama-French 五因子包含市场、规模、价值、盈利能力和投资；动量是另一个常用因子。

## 4. 流动性、订单和执行成本

| 指标 | 常用口径 | 用途与限制 |
| --- | --- | --- |
| 相对买卖价差 | `(卖一价 - 买一价) / 中间价`，其中中间价为买一和卖一均值 | 衡量即时交易成本；不同交易场所不可直接合并 |
| 盘口深度 | 距离中间价指定百分比范围内的买卖挂单金额 | 衡量潜在承接能力；挂单可能撤销 |
| 静态盘口不平衡 | `(买盘量 - 卖盘量) / (买盘量 + 卖盘量)` | 描述某一时点挂单结构；需固定档位和单位 |
| 订单流不平衡 OFI | 一段时间内新增、撤销与成交造成的买卖供需变化 | 研究短期价格冲击；定义和数据质量影响结果 |
| 主动买卖成交差 | 主动买入成交金额减去主动卖出成交金额 | 描述成交方向；需了解交易所分类方法 |
| 成交量与成交金额 | 指定窗口内的交易数量或计价金额 | 描述活跃程度；注意异常成交与口径差异 |
| 预估滑点 | 模拟订单成交均价相对下单时基准价的偏差 | 依赖订单规模、盘口、延迟和成交方式 |
| 价格冲击 | 一定订单规模导致的成交价或市场价格变化 | 评估容量；需区分暂时冲击与持续冲击 |

静态盘口不平衡看的是快照，OFI 看的是订单事件变化。成交成本还包含手续费、延迟、部分成交和未成交机会成本，不能只用单次静态价差替代。

## 5. 衍生品与持仓

| 指标 | 含义 | 使用注意 |
| --- | --- | --- |
| 资金费率 Funding | 永续合约多空双方定期交换的费用费率 | 统一结算周期和正负号；不能单独判断未来涨跌 |
| 未平仓量 OI | 尚未了结的合约规模 | OI 增长不直接表明多头或空头占优；注意单边和双边统计口径 |
| OI 变化率 | 指定窗口内未平仓量的变化 | 区分合约数量变化和标的价格导致的名义价值变化 |
| 期现基差 | 期货价格与现货价格之差，或相对于现货的比例 | 注意合约到期日、资金成本与交割规则 |
| 清算量 | 被强制平仓的头寸规模 | 区分名义金额与实际损失；数据源覆盖可能不完整 |
| 隐含波动率 IV | 在选定定价模型下，从期权价格反推的波动率参数 | 依赖行权价、到期日和模型假设 |
| 波动率偏斜 Skew | 不同行权价或不同 Delta 期权的隐含波动率差 | 衡量不同方向保护的相对价格；需固定期限和计算方式 |

这些指标更适合作为市场状态或条件变量。高资金费率可能对应拥挤，也可能与持续趋势并存；单独使用不能推断价格一定反转。

## 6. 加密资产供给与链上指标

| 指标 | 常用口径 | 用途与限制 |
| --- | --- | --- |
| 流通市值 | 价格 × 流通量 | 取决于供应商对流通量的定义 |
| 完全稀释估值 FDV | 价格 × 数据源采用的完全稀释供给 | 最大供给、总供给和未来发行假设可能不同，必须记录口径 |
| 解锁规模 | 未来指定期间的解锁数量或名义金额 | 解锁不等于实际流入交易所或卖出 |
| 发行与代币激励 | 指定期间新增发行或用于激励的代币数量及价值 | 应记录价格时间点和接收方 |
| MVRV | 市值 / 已实现市值 | 已实现市值是链上成本代理，不等于所有持有人的准确成本 |
| NVT | 市值 / 指定期间链上转账金额 | 不同口径对内部转账、交易所转账与稳定币处理不同；转账额不是利润 |
| 交易所净流入 | 指定期间进入交易所地址的数量减去流出数量 | 依赖地址标注；内部转移和托管变更可能污染数据 |
| 活跃地址数 | 指定期间参与链上活动的唯一地址数量 | 地址不等于用户；需处理机器人和批量交易 |

链上指标应按链、代币和供应商单独确认计算方法。账户模型、UTXO 模型、交易所托管与链上合约使用方式都可能影响可比性。

## 7. 协议基本面与代币价值捕获

| 指标 | 含义 | 容易混淆的地方 |
| --- | --- | --- |
| TVL | 协议锁定或管理的资产价值，具体范围依供应商定义 | 用户存入资产不等于协议收入或协议自有资产 |
| 用户费用 Fees | 用户使用协议支付的费用 | 费用不一定全部由协议保留 |
| 协议收入 Revenue | 按数据源口径归属于协议的费用或收入 | 与支付给流动性提供者、验证者的部分区分 |
| 代币持有人收入 | 按明确规则实际流向持有人的现金流或其他分配 | 协议收入不自动等于代币持有人收入；回购需注明资金来源和去向 |
| 激励后收益 | 按明确口径计算的协议或持有人收入减去代币激励成本 | 必须区分现金流与增发稀释，避免重复扣减 |
| 交易量、借款余额 | 协议业务活动规模 | 业务规模不等于利润，需结合费用与激励 |

可研究的派生变量包括 `流通市值 / 过去 12 个月代币持有人收入`、`过去 12 个月代币持有人收入 / 流通市值`、收入增长率和激励增长率。分母为零或负值时，不应强行解释倍数；短期收入年化会放大异常值。所有统计均应确认代币是否真实享有相关价值。

## 8. 利率与期限结构

| 指标 | 含义 | 用途与限制 |
| --- | --- | --- |
| 无风险或低信用风险利率曲线 | 不同期限的基准利率 | 折现时匹配币种、期限和现金流口径 |
| 预期短期利率路径 | 市场或模型对未来短端利率的估计 | 用于研究融资及折现环境，估计方法不同会产生差异 |
| 期限溢价 | 持有长期债券所要求的额外风险补偿的模型估计 | 不是可直接观察的唯一数值，不同模型结果可能不同 |
| 信用利差 | 信用债与同币种、相近期限基准债券的收益率差 | 同时受违约、流动性和其他风险影响 |
| 实际利率或通胀预期 | 将名义利率与通胀相关数据结合得到的衡量 | 注意实际利率、盈亏平衡通胀率与真实通胀预期的区别 |

## 9. quantmp 第一阶段：最小可研究指标集

目标是验证一个明确假设，而非一次接入所有指标。初学者可先以单一交易所的现货数据为主，衍生品数据仅用于观察或研究。

| 模块 | 候选指标 | 目的 |
| --- | --- | --- |
| 价格表现 | 多周期收益率、相对 BTC 的收益 | 分清绝对表现与相对表现 |
| 市场影响 | 滚动 Beta、剔除市场影响后的收益 | 研究资产自身偏离；用历史窗口估计，避免使用未来数据 |
| 风险状态 | 已实现波动率、当前回撤 | 分析风险状态和仓位约束 |
| 可交易性 | 成交金额、相对买卖价差、目标订单金额的预估滑点 | 衡量能否以预期成本成交 |
| 杠杆状态 | 资金费率、统一口径的 OI 变化 | 检验是否提供基准之外的信息；不要求使用杠杆交易 |
| 后续扩展 | 按资产类型选取 MVRV、协议收入等 | 检验较低频估值信息是否有增量价值 |

### 一个可检验的研究问题

> 某现货资产在扣除此前估计的市场影响后出现异常下跌，未来收益更倾向反转还是延续？结果在计入成本后是否仍然存在？

1. 事先定义资产范围、基准、观察频率、回看窗口、持有时间和异常阈值。
2. 仅用决策时已经可获得的数据估计 Beta；记录数据发布时间、采集时间和可用时间。
3. 与简单基准比较，按时间顺序滚动训练和测试，保留未参与选参的最终测试期。
4. 纳入手续费、价差、滑点、延迟、最小下单量及成交限制，并比较更差的成本情景。
5. 可以先用多空分组研究收益差；若计划只做现货，应单独测试只做多、允许空仓的可执行版本。
6. 记录失败实验、换手率、回撤、样本外结果和不同市场状态下的表现；近期正收益不等于优势已被证实。

### 指标元数据模板

每项指标至少记录：

```text
名称与版本：
用途：估值 / 预测研究 / 风控 / 执行成本
适用资产与交易场所：
公式、单位、频率与窗口：
原始数据来源、授权与口径：
事件时间、发布时间、采集时间、可用时间：
缺失值、修订、异常值处理：
研究假设、基准与失败条件：
样本外表现、成本假设与容量限制：
```
