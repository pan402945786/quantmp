# 2026-11-11 策略与组合优化记录

## 观察

上一版 `research_loop_config.json` 的动态组合长期退回现金，期末权益为 77,606.27，净收益为 -22.39%，最大回撤为 -49.68%。这不是账务审计错误，而是选择器在验证证据不足或风险调整后分数不为正时使用现金回退。

独立影子账户显示：动量和等权策略的历史收益较高，但最大回撤分别达到 -74.39% 和 -89.31%，同时动量换手和费用很高；跌幅回归策略期末亏损且回撤更差。全历史结果不能直接作为未来收益保证，因此本轮优化优先降低暴露和换手。

## v2 方案

`paper_v2_config.json` 是一条新的、独立的实验协议，旧检查点和旧配置继续保留。

- 动量窗口由 5 日改为 20 日，降低短周期反复调仓。
- 实际组合预算改为动量 50%、现金 50%，给风险和模型失效留下缓冲。
- 选择器候选改为动量和等权，暂时移除表现较弱的跌幅回归候选。
- 选择器的策略预算限制为 50%，即使选中策略也不会把全部资金投入风险资产。
- 30 日动量候选只有通过训练、验证和至少 90 天的前向影子确认后才可生效。此次冻结回放中它已经内部验证失败，唯一一次研究预算已耗尽，不会自动重新尝试或进入 90 天确认。

这些修改是待验证假设，不是收益承诺。固定预算组合是当前纸面运行的主控制方案，动态选择器和候选研究用于影子比较。
